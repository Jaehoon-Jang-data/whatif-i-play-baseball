# 스토브리그·시즌 진행·은퇴 보관 점검

2026년 10월 6일 코드 기준의 상태 전이 점검이다. 야구 규정 변경이 아니라 화면과 게임 진행 순서를 바로잡은 작업이다.

## 겨울 의사 결정 순서

시즌 결과의 수상·포스트시즌·국제대회 이벤트를 확인한 뒤 `다음`을 누르면 다음 연도 스토브리그 진입을 판정한다. 만 28세 미필자의 입대, 은퇴 권고, 보직·포지션 변경 제안, FA·2차 드래프트·보류선수 제외, 연봉 협상, 시즌 준비와 개막의 순서다. 은퇴 권고 대상 여부를 **보직 변경 제안을 만들기 전에** 평가한다. 권고 대상은 스토브리그 첫 화면에서 권고를 받고 같은 겨울에 보직 제안을 받지 않는다. 권고를 수락하면 은퇴하고, 거절하면 기존의 자유계약 경로로 이동한다. 보직 제안을 받은 선수는 수락·거절 결과를 구단 이동 알림보다 먼저 확인한다. 저장·복구 중에도 결정 단계와 이벤트 대기열을 유지한다.

## 진행 바와 부상

이전에는 시즌 결과를 이미 계산한 뒤 24칸을 180ms마다 재생해 최소 4.32초 동안 진행 바가 남았다. 계산이 짧아도 바가 남았고 표시 속도를 일률적으로 1.3배 높이면 같은 불일치가 남는다. 이제 작업 스레드가 실제로 처리한 경기 수를 12개 구간으로 전달하고, 완료 결과가 도착하면 바로 결과 화면으로 전환한다. 경기 계산 뒤 수상·성장 등 후처리가 끝나기 전에는 100%로 표시하지 않는다. 따라서 고정된 1.3배 배속은 적용하지 않았다. 계산이 매우 빠른 시즌은 중간 칸을 눈으로 보기 어려울 수 있다.

부상이 예고된 경우 시즌 화면에 **부상 시점 미리보기 · 재활 결정 대기**라고 명시한다. 이는 계산 진행률이 아니다. 재활 방식을 고르면 실제 경기 계산 진행률을 0에서 시작한다. 작업 중 새로고침하면 완료되지 않은 계산 결과를 저장하지 않고 시즌 진입 화면으로 돌아가며, 이미 선택한 재활 방식은 유지한다. 브라우저가 작업 스레드를 지원하지 않으면 메인 스레드 계산 후 결과로 곧바로 이동한다.

## 우승 표시와 병역 일정

한국시리즈 결과의 `한국시리즈 우승!` 문구는 유지하고 CSS의 폭죽 장식을 제거했다. 병역 패널은 `militaryOpportunities()`에서 아시안게임만 받는다. WBC·프리미어12 일정과 개인 대회 결과는 시즌의 국제대회 화면에 그대로 남는다.

## 은퇴 기록

누적 기본 연봉은 `salaryLedger`의 시즌별 `salaryMan`만 더한다. 계약금·성과 옵션 지급·군 보류수당은 별도 항목이며 기본 연봉 합계에 넣지 않는다. 은퇴 화면과 은퇴 선수 순위 상세에 이 기준을 표시한다. 보관 항목에는 1·2군 시즌 원기록, 수상, 포스트시즌, 국제대회 결과, 연봉 지급 내역, 계약금 합계를 저장한다. 은퇴 선수마다 생성 시 정한 고유 ID로 보관하고 같은 선수의 재저장은 해당 항목만 갱신한다. 새 선수 생성과 새로고침은 기존 보관 항목을 지우지 않는다.

기존 은퇴 보관 항목에는 연봉 원장이 없는 경우가 있다. 과거에 저장하지 않은 연봉을 추정하지 않고 `미기록`으로 표시한다. 보관은 브라우저 `localStorage`에 남으므로 해당 브라우저 저장 공간을 삭제하면 기록도 사라지며 저장 용량 제한을 받는다. JSON 내보내기는 현재 활성 커리어만 포함하고 별도 은퇴 보관 목록은 포함하지 않는다.

## 검증

`node --test tests/*.test.js`로 상태 전이·저장 복구·은퇴 보관 중복 방지·누적 연봉·실제 경기 진행률의 단조 증가를 검사했다. 별도 로컬 포트 브라우저에서는 고교 시즌 시작→계산 완료 직후 결과 전환, 결과 후 진행 바 제거, 은퇴 누적 연봉 표시와 새로고침 뒤 보관 목록 유지를 확인했다. 이 화면 표본의 연봉은 0원이었다. 비영(非零) 연봉의 합계와 수상·시즌 기록 보존은 저장 데이터를 사용한 회귀 테스트로 확인했다. 브라우저별 작업 스레드 부재, 저장 공간 부족, 전 선수 유형의 겨울 사건 조합은 전수 확인하지 않았다.
