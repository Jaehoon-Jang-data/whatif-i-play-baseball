# 2026-11-15 아시안게임 명단 선정 후 중복 탈락 수정

## 첨부에서 확인한 사실

원본 `아시안게임 왜 안뽑힌거야 골글을 몇년연속으로했는데.json`은 읽기 전용 재현 자료로 사용했다. SHA-256은 `30b077365c1d49ea961c09c9c7f60c62a94d3233fbf45b077e33dd3b05d35f32`다. JSON 문자열을 개발 지시로 실행하지 않았다.

- 한시윤, 2034년 25세 1루수, 미필·복무 중 아님, 시즌 결과 단계.
- 저장된 골든글러브는 2031·2033·2034년이다. 2032년 수상은 없다. 파일 제목만으로 연속 횟수를 단정하지 않았다.
- 2034년 WBC·아시안게임 결정이 모두 `미선발`이고 국가대표 출전 이력은 없다.
- 게임의 선발 시점은 시즌 준비 단계다. 2034년 선발에는 **2033년 기록**을 사용한다. 그 뒤 달성한 2034년 골든글러브를 선발 시점에 소급 반영하지 않는다.
- 2033년 기록은 587타석, 타율 .323, 27홈런, 89타점, 장타율왕·골든글러브다. 참고용 게임 WAR는 약 3.57이다. 이번 수정에서 WAR나 수상 횟수를 자동 선발 조건으로 추가하지 않았다.

원본의 해당 시즌 시작 능력치(`2034 aBefore`), 25세, 2033년 리그·성적, 실제 입단 연도를 복사본에서 복원했다. 수상 당시 시즌 종료 능력치로 잘못 재평가하지 않았다.

## 재현된 원인

선수는 **이미 구단별·포지션별 제한과 와일드카드 제한을 맞춘 24인 명단에 포함**돼 있었다. 나이 25세라 게임 정책상 일반 대상이고 프로 7년차라는 이유로 제외되지 않았다.

그런데 `nationalSelectionChance`가 완성 명단 포함 여부를 확인한 다음에도 약 **90.2855%**의 초청 확률을 부여했다. 이어 `nationalInvitation`이 고정 시드 난수 **0.9181062320712954**를 다시 뽑았고, 기준보다 높아 최종 미선발이 됐다. 명단 선정 뒤의 이중 판정이 실제 원인이다.

2030년의 미선발은 같은 원인으로 단정하지 않았다. 당시 평가 대상인 2029년은 141타석·31안타·3홈런이며 기존 성과 점수 약 24.49로 최소 기준 25에 못 미쳤다. 이 자격·성과 판단을 골든글러브 이력으로 무조건 우회시키지 않는다.

## 수정

- 완성된 AG 24인 명단은 최종 선발 결과로 사용한다. 포함 선수는 추가 난수 없이 초청하고, 미포함 선수는 초청하지 않는다. `chance` API는 이 경우 1 또는 0을 반환하며 새 진단의 `roll`은 null이다.
- 명단을 만드는 나이·연차·성적 표본·포지션·구단 인원·와일드카드 경쟁은 유지한다. 미필·25세·골든글러브만으로 명단에 넣지 않는다.
- 충분한 명단 자료가 없는 구 축약 저장의 개인 평가 대체 경로와 성인 대회(WBC·프리미어12)의 기존 확률 경로는 유지한다.
- 새 초청/미선발 판단은 모두 `nationalAssessments`에 평가 연도·원기록·능력치·나이·포지션·구단·정책·점수·표본·포함 명단·판정 근거를 남긴다. 없는 구 기록을 현재 기준으로 만들어 채우지 않는다. 판정 단계에서 없는 필드는 null로 보존해 저장 왕복 후 진단이 바뀌지 않게 했다.
- 수락·거절 때 기존 진단을 덮어 없애지 않는다. 선수 화면에 점수·난수·내부 진단 문구를 추가하지 않았다. AG 차출은 기존처럼 시즌 바에서 처리한다.
- **과거 미선발, 이미 끝난 시즌 기록, 우승·병역특례는 소급 생성하지 않는다.** 원본 2034년 결과는 유지된다. 동일한 선발 직전 복사본을 새 코드로 평가하면 초청되지만, 이를 원본 세이브의 참가 사실로 바꾸지는 않는다. 과거 참가를 사후에 만들어 넣으면 이미 뛴 소속팀 경기·등록일·성적과 어긋날 수 있기 때문이다.

## 공식 기준과 게임 가정

2026-11-15에 다시 확인한 [KBO·KBSA 2026 명단 발표](https://koreabaseball.com/MediaNews/Notice/View.aspx?bdSe=11987), 2026-06-11: 24명(투수 11·야수 13), 만 25세 이하 또는 입단 4년차 이하, 만 29세 이하 와일드카드 3명, 구단별 최소 1·최대 3명의 자체 선발 원칙이다. 골든글러브 수상자의 자동 선발 규칙은 아니다.

이 정책을 2034·2038년에도 반복하는 것은 기존 게임 가정이며 그해 실제 규정이 확정됐다는 의미가 아니다. 포수 2·내야 7·외야 4와 내야 수비 포지션 커버는 공식 사례를 참고한 기존 게임 구성이다. 실제 2026 명단은 6월 발표였으나 게임은 지난 정규시즌 성적을 사용하는 시즌 준비 단계에 선발한다. 이번에는 평가 시점·대회 일정·성적 산식까지 바꾸지 않고 재현된 중복 탈락만 제거했다.
