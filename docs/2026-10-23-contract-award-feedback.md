# 2026-10-23 첨부 7건: 계약·수상·대표팀 감사

## 자료와 재현 범위

원본 Downloads 파일은 읽기만 했다. 파일명은 증상 메모로만 사용하고 실제 기록을 비교했다. 확장자가 없는 2034년 파일도 JSON으로 읽었다. 원본 사본과 원본에서 추린 전체 로스터는 저장소에 포함하지 않는다. 공개 회귀 fixture는 오류 조건을 따로 작성한 가상 선수·리그이며 원본의 이름·파일명·시드·해시는 포함하지 않는다. 실제 7개 파일 비교는 로컬 전용 `--attachments` 감사와 브라우저에서 수행했다. 원본의 이미 확정된 수상·이적·계약·지급 내역을 소급해서 재작성하지 않는다. 아래 수상 전후는 **같은 원기록을 수정 산식으로 재평가한 결과**이며, 기존 저장을 불러왔을 때 과거 수상이 바뀐다는 뜻은 아니다. 아직 서명하지 않은 2056년 시장 제안에는 새 산식이 바로 적용된다.

## 원인과 변경

### FA·연봉·구단 예산

- 2056년 실제 상태는 47세 마무리, FA 시장이다. 직전 보류 연봉은 91억 2,400만원이었다. 2055년은 12경기·12이닝·10세이브·ERA 6.75이며, 최근 3시즌은 33/36/12경기다. 단순히 고령의 최고 성적 선수라고 볼 수 없다.
- 기존 연봉이 매년 인상률과 기존 연봉 비례 수상 보너스로 누적됐다. 2028년 이후 예산에도 매년 4% 증가를 적용했다. FA의 `예상 보류 연봉 이상` 하한이 이렇게 부풀어 오른 연봉을 다시 계승했다.
- 최근 3시즌 생산성과 출장량, 현재 보직, 최근 수상, 나이로 다음 시즌 가치를 추정하고 기존 인상 제안의 상한으로 사용한다. 저연봉 선수의 급격한 삭감 완충은 유지한다. 확정된 FA 다년계약의 연봉은 중도에 재평가하지 않는다.
- 2029년 이후에는 확인된 2028년 예산을 유지한다. 이는 **미래 규정 예측이 아닌 게임 가정**이다. 신규 FA는 동일 가치와 구단 수요에서 출발하고 계약금·옵션을 포함한 연평균 비용을 여유 예산 안으로 제한한다. 여유가 부족하면 옵션·계약금을 줄이고, 기본 연봉조차 감당할 수 없으면 제안하지 않는다. 보장 연봉은 예상 보류 연봉보다 높다.
- 40세 이상 단년, 37~39세 2년, 34~36세 2~3년, 젊은 선수 최대 6년이다. 연령 할인율·보직별 가치·예산 배분은 게임 가정이며 실제 계약 제한이 아니다.
- 첨부 제안은 수정 전 2년 최대 **211.65~255.49억**, 연봉 80.7억이었다. 수정 후 1년 최대 **0.6~0.8억**, 연봉 0.5억이다. 전자는 현행 이전 코드로 원본을 평가한 값이며, 파일 제목의 “200억”은 이를 대략 지칭한다.

### 금액 표시·동결

- 1억 이상은 소수점 첫째 자리로 표시한다. 18,500만원과 18,700만원은 모두 `1.9억`이다. 증감도 표시 단위로 계산해 `동결`로 표시한다.
- 표시 구간이 같으면 실제 새 연봉도 이전 금액 그대로 확정한다. 위 예에서는 18,500만원을 유지하며 숨겨진 200만원을 지급하지 않는다. 다른 구간이면 새 제안을 1,000만원 단위로 확정한다. 1억 미만은 만원 표시를 유지한다.
- 과거 확정 계약·계약금·실지급 옵션·급여 원장에는 표시 반올림을 소급하지 않는다. 총수입은 계속 실제 지급 원장으로 합산한다.

### MVP와 신인왕

- 기존 MVP는 타자 OPS·누적 기록과 투수 ERA·이닝에 서로 다른 척도를 썼다. 2041년 20승 2패·171이닝·ERA 1.11·투수 4관왕도 타자 2.437점에 밀린 2.034점이었다.
- 새 MVP·신인왕은 리그 평균 대비 타격 득점 기여와 실점 억제를 출장량에 곱해 비교한다. 주루·수비 기록, 구원 역할을 제한적으로 더한다. 투수 쪽 점수는 수비 기여 공유와 표본 균형을 위한 0.87 보정을 적용한다. 이는 **공식 WAR가 아닌 게임 근사식**이다. 타자·투수 간 비교가 목적이며 골든글러브·최동원상 산식은 그대로다.
- 투수 다승·평균자책점·삼진 3관왕에는 6점 가점을 주지만 자동 MVP로 정하지 않는다. 수상 개수만으로 결정하지 않고 원기록이 주된 값이다. 압도적인 타자도 수상하는 회귀 조건을 넣었다.

- 2028년 플레이어는 14승·154이닝·ERA 2.75였다. 기존 신인왕은 34세 임태준, 507타석·18홈런·OPS .905이었다. 플레이어 자격 누락이 아니라, 초기 AI 명단이 경력 없이 나이와 무관하게 무작위 신인 표시를 부여했고 투타 점수 차이까지 겹친 사례다.
- 생성 명단에서 경력 불명 베테랑을 임의 신인으로 만들지 않는다. 실제 입단 연도와 전년도 누적 출장량이 있는 선수는 나이로 배제하지 않는다. 해외 프로 경력, 5년 기한, 전년도 60타석·30이닝 기준을 평가한다. 게임의 당해 수상 표본 하한은 그대로다. 같은 기록을 재평가하면 2028 신인왕은 플레이어다.

### 핵심 선수 트레이드

2035년 파일은 현재 연도 2035, 마지막 완료 시즌 2034이며 타이틀 7개와 이적 이벤트가 저장돼 있다. 직전 시즌 다승·ERA·삼진·승률 1위다. 기존 자동 이적은 현재 능력과 계약 유형만 사용했고 타이틀과 다년 기여를 고려하지 않았다. 최근 3시즌 핵심 수상과 직전 시즌 주전 활약에 보유 가중치를 더했다. 첨부 선수의 자동 이적 확률은 1.05%에서 0.04%로 낮아졌다. 이미 저장된 2035년 이적을 취소하거나 과거 팀을 바꾸지는 않는다. 구단 간 AI 거래·마감일·이적 시즌 기록 분할은 유지한다. 트레이드 대가를 구단 자산 가치로 정산하는 완전한 단장 시뮬레이션은 여전히 구현하지 않는다.

### WBC·아시안게임

- “2031” 파일의 실제 결정은 **2030 WBC 수락 / 2030 아시안게임 미선발**이다. WBC는 2029년 기록(13승·150이닝·ERA 4.02)을 평가했다. 2030년 결과의 12승·ERA 2.68을 당시 선발 자료로 사용한 것이 아니다.
- 해당 선수는 21세로 두 대회에 모두 자격이 있었으나 별도 난수를 사용했다. 아시안게임 난수 0.9388이 선발 확률보다 커 미선발됐다. WBC 초청이 아시안게임 초청을 보장하는 누락 규칙은 만들지 않았다. 미필도 자동 선발 자격이 아니다.
- 추가로 완료 프로 시즌 수 4를 “4년차”로 허용하던 경계를 수정했다. 4시즌 완료 선수는 다음 시즌 5년차다. 동료의 무작위 신인 표시도 연령 예외로 쓰지 않는다. 미래 대회는 2026년의 25세 이하 또는 프로 4년차 이하, 29세 이하 와일드카드 3명 정책을 적용하는 게임 가정이다. 실제 미래 명단·선발 시기는 확정하지 않는다.
