# 2026-10-27 팀 이력·상무·포스트시즌·아시안게임

## 첨부 자료 확인

원본 JSON 3개는 로컬에서 읽기만 했다. 공개 회귀 테스트는 별도로 작성한 가상 데이터이며, 사용자 저장·전체 로스터·시드를 저장소에 넣지 않았다.

- **마지막 2차 드래프트**: 2049년 2차 드래프트로 구단 1에서 구단 0으로 이동했고 2050년에는 구단 0에서 뛰었다. 기존 은퇴 화면이 시즌 소속을 `Set`으로 만들면서 처음 뛰었던 구단 0으로의 복귀를 없앴다. 실제 이동 순서는 `0 → 7 → 4 → 1 → 0`이다. 새 팀 이력은 시즌 기록·시즌 중 이적 구간·FA·이적 이벤트를 시간순으로 합치고 **연속 중복만 제거**한다. 경기 출전 전 이적 후 은퇴한 경우도 현재 소속을 남긴다. 새 은퇴 보관에는 이 순서를 함께 저장하며, 화면과 내보내기·복원에서도 유지한다. 기존 보관만 남아 있고 출전 전 이적 자료가 없는 경우 누락된 방문을 추측하지 않는다.
- **신인왕 출신 상무 탈락**: 2033년 65경기·280타석·신인왕, 2034년 상무 탈락이 실제 저장돼 있다. 기존 식은 직전 기록과 기량만 보며 수상을 쓰지 않았고 최대 확률도 72%였다. 같은 상태의 확률은 35.19%였다. 최근 3시즌의 신인왕·MVP·골든글러브 실적을 시점에 따라 가중하고 상한을 96%로 조정해 81.54%가 됐다. 수상은 자동 합격 조건이 아니며 동포지션 경쟁, 나이·미필·복무 상태와 연간 재지원 제한을 유지한다. 기존 탈락 결과를 합격으로 소급하지 않는다.
- **포스트시즌 로스터**: 2033년 49경기·75타석과 2036년 30경기·41타석 선수가 시즌 마지막 1군이라는 이유로 선발돼 있었다. 2034년 말 2군·2035년 복무 때에는 이미 미선발이었다. 특히 2036년은 OPS .382이고 같은 팀 3루수 중 .731·.779를 기록한 대안이 있었다. 1군 등록·건강 조건에 최근 부진·기량·동포지션 경쟁을 더해 두 문제 시즌은 재평가상 미선발이 됐다. 2033년은 적은 타석 자체의 금지보다 동포지션 경쟁 후순위가 이유다. 높은 수비·송구의 수비 전문 선수는 낮은 타격 기록만으로 자동 배제하지 않는다. 확정된 과거 포스트시즌 출장·우승 기록은 다시 쓰지 않는다.

## 아시안게임 일정과 진행 화면

- 기존 달력은 마지막 18칸을 대표팀으로 덮어 시즌 끝까지 복귀하지 않았다. 결과 팝업도 시즌 결과 큐에서 보여줬다.
- 게임의 미래 대회는 **9월 20~29일 열흘 차출, 30일 복귀**로 단순화했다. 같은 날짜 함수를 1군·2군 출전 자격과 재생 정지 지점에 사용한다. 파견 직전·복귀 뒤의 원래 소속 상태를 유지하고 재활 상태를 대표팀으로 덮지 않는다. 거절·미선발·복무 중에는 차출하지 않는다.
- 진행 바가 시즌 중 해당 지점에 도달하면 `대표팀 차출`을 확인하고, 열흘 구간을 지난 뒤 `대회 결과·소속팀 복귀`를 확인한다. 아직 남은 정규시즌을 이어간다. 확인한 결과는 시즌 말 알림에서 다시 띄우지 않으며 시즌 결과와 국제대회 이력에는 남긴다.
- 기존 배치 계산·부드러운 시간 기반 재생은 유지했다. 실제 경기를 날짜별로 스트리밍 계산하도록 바꾼 것은 아니다. 계산은 한 번 하고, 표시·확인·선택을 시즌 중 순서대로 재생한다. 중단 지점과 확인 연도만 자동 저장하고 재시작 때 같은 시드로 미확정 시즌을 재계산해 이어간다. 계산 후보 전체를 자동 저장에 중복 넣지 않는다. 다른 저장을 불러오면 이전 계산의 늦은 응답을 무시한다.
- 팝업을 그릴 때 반올림된 퍼센트로 날짜를 역산하던 경계도 수정했다. 정밀 진행 위치를 사용해 차출 팝업에서 `현재 대표팀`, 복귀 때에는 원래 구단 상태가 보이게 했다.
- 우승 확률은 **43% → 55%**로 조정했다. 이는 사용자가 요청한 게임 난이도 변경이며 실제 한국 대표팀의 우승 확률 추정이 아니다. WBC·프리미어12 확률과 병역특례 대상 대회는 바꾸지 않았다. 아시안게임 선발·우승 때만 기존 특례 규칙을 적용하며 같은 대회 결과를 중복 생성하지 않는다.

## 검증

- 전체 `node --test tests/*.test.js`: **180개 통과, 실패 0**. 새 8개 회귀 테스트는 복귀 이적·은퇴 보관·저장 복구, 수상과 상무 자격, 부진·수비 전문 역할의 포스트시즌 판단, 대회 날짜·불출전·복귀, 우승률, 특례·결과 중복, 이적→차출→복귀 정지 순서를 다룬다.
- 고정 시드 10,000개에서 아시안게임 우승 **4,349 → 5,592회**. WBC·프리미어12의 난수별 결과는 이전 9% 기준과 일치했다.
- 상무 가상 선수 1,000시드씩: 같은 능력·기록에서 야수 일반 429회, 직전 신인왕 429→914회; 선발 일반 485회, 직전 신인왕 485→953회. 이 표본은 실제 모집 정원이나 실제 경쟁률을 복원한 것이 아니다.
- 3시드 × 타자·선발 × 4시즌, **24시즌씩 전후 비교**: 대회가 있는 2030년 차출은 18칸→10칸, 시즌 말 대표팀 상태는 사라지고 구단으로 복귀했다. 1군 등록·출장 명단 위반은 양쪽 모두 0. 개인 포스트시즌 선발은 8→10회로, 단순히 선발 수를 낮추려는 조정이 아니다. 차출 뒤 복귀와 성적·경쟁을 함께 반영한 결과다.
- 별도 Chrome에서 원본 3개를 불러와 오류·모바일 가로 넘침이 없었고, 은퇴 화면·보관 상세의 마지막 복귀 이적을 확인했다. 합성 시즌은 91% 차출·97% 복귀에서 멈췄으며 각 정지에서 새로고침 후 재개했다. 이적→차출→내보내기→새 세션에서 불러오기→복귀→시즌 종료도 통과했고, 최종 소속·원기록은 중단 없는 계산과 일치했다. 시즌 기록·국가대표 결과·이적 기록은 각각 한 번만 저장됐다.
- 재현 명령: `node scripts/late-season-feedback-audit.mjs --baseline=f82cab4`. 첨부 자료를 별도 확인하려면 `--save=/절대경로/저장.json`을 추가한다. 출력은 새 `/tmp/` 파일에 저장하며 원본이나 기존 감사물을 덮어쓰지 않는다.
