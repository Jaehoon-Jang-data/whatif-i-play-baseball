# 훈련 상한과 시즌 진행 표시 조정

2026년 10월 7일 코드 기준. 이는 게임 화면과 성장 계산 규칙이며 KBO 공식 규정은 아니다.

## 진행 바

처음에는 작업 스레드가 완료한 경기 수에 따라 바를 움직였으나, 계산이 빠른 기기에서는 화면이 너무 빨리 지나갔다. 이제 계산 속도와 독립적으로 24칸을 240ms마다 움직인다. 과거 고정 재생의 180ms/칸을 기준으로 절대 표시 속도를 0.75배로 낮춘 것이며 총 표시 시간은 5.76초다. 계산이 먼저 끝나면 남은 진행 장면을 재생하고, 계산이 늦으면 23칸(96%)에서 결과를 기다린다. 결과 화면은 계산과 표시가 모두 끝났을 때 열린다. 따라서 바는 더 이상 실제 완료 경기 비율을 뜻하지 않는다. 시뮬레이션 자체의 실행 속도와 기록 결과는 바꾸지 않는다.

## 훈련 상한

선택된 능력치가 현재 상한 이상이면 훈련 중점에서 자동 해제한다. 상한 항목은 버튼을 비활성화하고 저장·불러오기·시즌 계산에서도 동일하게 제외한다. 선택 가능 항목이 모두 상한이면 중점 없이 시즌을 진행한다. 이 경우 기본 성장·노화의 변동은 계속 계산하며, 시즌 결과의 훈련 기록에는 실제 적용한 중점만 남긴다. 시즌 종료 시 새로 상한에 도달한 중점은 다음 시즌 선택에서 제거한다.
