# 훈련 상한과 시즌 진행 표시 조정

2026년 10월 7일 코드 기준. 이는 게임 화면과 성장 계산 규칙이며 KBO 공식 규정은 아니다.

## 진행 바

기존 작업 스레드는 실제로 완료한 경기 수를 12구간으로 보고했다. 새 표시 함수는 각 구간의 초반·중반 이동 폭을 이전 값의 약 0.8배로 계산한다. 후반부에는 완료 경기 수를 따라잡도록 곡선을 더한다. 정확히 전 구간을 0.8배로 유지하면 계산 완료 시 바가 약 80%에 남으므로, 계산 완료와 결과 화면 전환을 일치시키기 위한 선택이다. 표시값은 실제 완료 경기 수를 넘지 않고, 계산이 끝난 뒤 타이머로 진행 바를 남기지 않는다. 시뮬레이션 자체의 실행 속도와 결과는 바꾸지 않는다.

## 훈련 상한

선택된 능력치가 현재 상한 이상이면 훈련 중점에서 자동 해제한다. 상한 항목은 버튼을 비활성화하고 저장·불러오기·시즌 계산에서도 동일하게 제외한다. 선택 가능 항목이 모두 상한이면 중점 없이 시즌을 진행한다. 이 경우 기본 성장·노화의 변동은 계속 계산하며, 시즌 결과의 훈련 기록에는 실제 적용한 중점만 남긴다. 시즌 종료 시 새로 상한에 도달한 중점은 다음 시즌 선택에서 제거한다.
