# 훈련 상한과 시즌 진행 표시 조정

2026년 10월 7일 코드 기준. 이는 게임 화면과 성장 계산 규칙이며 KBO 공식 규정은 아니다.

## 진행 바

작업 스레드의 완료 경기 수에 맞춘 표시와 고정 240ms/칸 표시를 거쳤으나 사용자가 이전 재생 방식을 요청했다. 현재는 시즌 결과 계산 후 **24단계·180ms/단계, 총 4.32초**의 독립된 진행 장면을 재생한다. 계산이 늦어도 바가 먼저 끝나지 않으며, 계산이 끝난 뒤 재생을 시작한다. 부상 예고 때는 같은 속도로 부상 지점까지 재생하고 재활 선택 후 그 위치부터 나머지를 재생한다. 바는 실제 연산 완료율을 뜻하지 않는다. 시뮬레이션 자체의 실행 속도와 기록 결과는 바꾸지 않는다.

기존 구현은 각 단계마다 전체 앱과 최대 188개 로스터 색 조각을 새로 그려 끊겨 보일 수 있었다. 현재는 한 번 만든 전체 로스터 막대의 보이는 영역만 `requestAnimationFrame`에서 갱신하고, 숫자와 현재 상태는 값이 바뀔 때만 수정한다. 저장소 쓰기도 단계마다 반복하지 않는다.

## 훈련 상한

선택된 능력치가 현재 상한 이상이면 훈련 중점에서 자동 해제한다. 상한 항목은 버튼을 비활성화하고 저장·불러오기·시즌 계산에서도 동일하게 제외한다. 선택 가능 항목이 모두 상한이면 중점 없이 시즌을 진행한다. 이 경우 기본 성장·노화의 변동은 계속 계산하며, 시즌 결과의 훈련 기록에는 실제 적용한 중점만 남긴다. 시즌 종료 시 새로 상한에 도달한 중점은 다음 시즌 선택에서 제거한다.
