# 선수 생성·훈련 표시와 공개 KBO WAR 대조

확인일 2026-11-06. 실제 비교 시즌은 **2024 KBO 정규시즌**이다. 이 문서는 특정 기관의 WAR를 정답으로 삼거나 게임 WAR와 동일한 모델이라고 주장하지 않는다.

## 화면과 저장 흐름

- 원인: 생성 마지막 `focus` 단계에서 포지션과 훈련을 동시에 선택하고 그 훈련을 새 선수에 복사했다. 제목도 ‘성장 방향 결정’이었다.
- 수정: `포지션 선택` 단계에서는 포지션만 정한다. 후보 다음 버튼은 `포지션 선택 →`, 생성 완료 버튼은 `고교 시즌 준비로 →`다. 포지션은 생성 초안과 선수 데이터에 반영하고, 새 선수의 훈련 선택은 비운다. 고교 준비 화면에서 기존 6개 프로그램 중 최대 2개를 선택한다.
- 구 초안의 `focus` 단계를 `position`으로 이관하고 후보·포지션은 보존한다. 초안의 옛 훈련 필드만 제거하며 기존 커리어의 훈련 선택은 변경하지 않는다.
- 훈련 효과는 주효과 `#1456b8 / 700`, 보조효과 `#1456b8 / 400`, 부담 `#b4232d / 400`으로 표시한다. 범례도 같은 클래스를 쓴다. 컨택·파워·제구·피로·부상 위험 등 실제 항목을 표시하고 추상적인 추천 문장은 렌더링하지 않는다. 반복 훈련·재활·연령에 따른 효율 제한과 상한 정보는 유지한다. 훈련 성장 계수는 변경하지 않았다.

주요 파일: `src/creation-flow.js`, `src/app.js`, `src/training-programs.js`, `src/training-ui.js`, `style.css`. ES 모듈과 CSS 캐시 참조를 7.20으로 올렸다.

## 동일한 기록을 게임 산식에 넣은 비교

공식 합계: 57,265 PA, 7,740 R, 1,438 HR, 1,152 SB, 397 CS, 12,789 IP. 10구단 × 144경기, 총 720경기다. 실제 득점 환경은 RA9 **5.447**, 게임의 득점/승은 `1.5 × RA9 + 3` = **11.170**이다. 공식 타격·투구 기본2 페이지의 서버 오류 때문에 BB/HBP/K 리그 합계는 상대편 기록 합계와 교차 사용했다. PA와 AB+BB+HBP+SH+SF는 2 차이가 나며 임의의 타격 결과로 채우지 않았다.

전체 합계를 두 개의 집계용 레코드로 재구성했다. 두 레코드는 실제 개별 선수 명단이 아니다. 포지션별 리그 수비 아웃은 경기 아웃 합계로 놓고 DH가 항상 있는 리그로 가정했다. 선발 이닝 비중은 실제 전수 자료가 없어 60% 가정, 50~65% 민감도를 별도 계산했다.

실제 구장 계수를 확보하지 못해 주 비교는 중립 구장이다. 전체 시즌 구장 노출 0.95~1.05의 민감도도 계산했다. 김도영 3B 1,111이닝, 김태군 C 641이닝, 박동원 C 944⅔이닝, 홍창기 RF 1,037이닝, 오지환 SS 858이닝을 사용했다. 부 포지션 누락 가능성이 있고 최형우 DH는 PA·경기 기반 출장량 추정이다. 실책으로 정밀 수비 득점을 만들지 않고 게임 수비 득점은 0으로 유지했다.

### 타자 차이를 일괄 보정하지 않은 이유

KBO Fancy Stats [공개 검색 색인](https://www.kbofancystats.com/index.json)의 2024 타자 282개 고유 페이지는 57,048 PA(공식 합계의 99.62%), WAR 합계 338.68이다. 투수 278개 페이지는 12,445⅓ IP(97.31%), WAR 110.20이다. 동명이인이 있으며 명단의 완전성과 개인 식별을 전수 확인한 공식 합계가 아니다.

게임은 시즌당 `1000 / 2430 × 경기 수` 대체 수준 WAR 풀, 타자 57%·투수 43%를 쓴다. 720경기에서 총 296.30, 타자 168.89·투수 127.41이다. 타자 표본의 공개 합계부터 게임 풀과 큰 차이가 있어 개별 시즌 차이를 전부 ‘공격 능력 과소평가’라고 해석할 수 없다. 공개 표본의 PA 가중 wRC+는 약 101.11, SFR 합계는 −6.4로, 단순히 누락된 양의 수비 득점만으로 그 차이가 설명되지는 않는다. **배분·정규화 등의 모델 차이가 관여한다는 추론**이며 해당 사이트의 오류 또는 정확한 미공개 공식을 확인한 것은 아니다.

수비 강점은 실제 SFR이 있지만 추적 자료와 동일하지 않으며 게임에는 그 수비 득점이 없다. SFR/RPW를 추가한 민감도는 진단에만 남기고 게임에 타기관 값을 이식하지 않았다. DH의 공개 SFR은 포지션 처리와 얽힐 수 있어 특히 단순 가산 비교로 해석하지 않는다. 타자 일괄 배율 조정은 하지 않았다. 현실 WAR와의 편향이 완전히 해소됐다고 주장하지 않는다.

## 산식 점검·수정과 중간값

- 타격: 안타 종류·볼넷·사구·아웃의 선형 득점에서 해당 시즌 PA당 평균을 뺀다. 주루는 SB/CS 기여에서 출루 기회당 리그 평균을 뺀다. 수비 득점은 0, 포지션 득점은 기록된 포지션별 이닝 비중, 리그 항목은 포지션 평균의 중심화다. 평균 중심화와 대체 수준 PA 비례 가산은 서로 다른 항목으로 한 번씩만 적용한다.
- 투수: `(13 HR + 3 (BB + HBP) − 2 K) / IP + 시즌 상수`를 실제 리그 RA9에 맞춰 중심화한다. FIP 계열 실점 추정과 실제 IP를 사용한다. 공개 FIP는 ERA 중심 상수일 수 있으므로 숫자를 같은 FIP 상수처럼 비교하지 않는다. 수비·레버리지는 따로 반영하지 않으며 승패·홀드·세이브를 직접 가치로 쓰지 않는다. 선발·불펜의 대체 수준 가산 이닝 가중치는 1:0.7이다.
- **확인된 오류:** 피사구가 제공된 실제 기록도 계산에서 무시했다. WAR v2는 리그 모든 투수와 해당 선수에 피사구 기록이 있을 때만 3×HBP를 반영하며 리그 상수도 같은 조건으로 재산출한다. 선수만 피사구를 넣고 리그에서는 빼는 불일치를 막는다.
- 기존 게임 투구 기록에는 피사구가 없어 새 기록을 만들어 넣지 않는다. 피사구 미기록 시즌 및 v1 보관 문맥의 값은 유지한다. 알려지지 않은 문맥 버전·다른 연도는 계산하지 않는다. 선택적 HBP 데이터의 저장·복구도 검사했다.

김도영의 수정 후 득점 구성은 타격 **57.855**, 주루 **5.616**, 수비 **0**, 포지션 **1.905**, 리그 중심화 **1.675**, 구장 **0**, 대체 수준 **20.590**이다. 합계 / 11.170 = **7.846 WAR**. 포지션이 어렵다는 이유를 수비 득점에도 다시 더하지 않는다. 투수의 실제 실점·자책은 진단에 남기지만 FIP 계열 기여에 이중 가산하지 않는다.

`seasonWAR()`는 `components`, `diagnostics`, `notes`, `runsPerWin`을 반환한다. 감사 JSON에도 각 선수의 중간값·구장·선발 비중 민감도를 출력한다. 수비 중립·구장 추정 등 사용자에게 필요한 한계 표시는 기존 결과 화면에 유지한다.

## 시뮬레이션과 검증

기준 커밋 `7a3651f`와 비교했다. 고정 시드 **48개 전체 리그 시즌**을 2024년으로 실행하고 타자 5포지션·투수 3보직, 능력치 65/80/92와 서로 다른 주루 능력을 섞었다. 각 실제 선수와 동일 포지션의 시뮬레이션 선수를 비교했다. 과거 커리어·수상·병역·이적의 재감사는 이번 범위가 아니다.

근접 후보의 허용 차이는 PA 100, AVG/OBP .040, SLG .080, HR 10, BB 20, SB 15, CS 6, 수비 이닝 250이다. 투수는 IP 30(불펜 15), G 6(불펜 20), RA9/ERA 1.0, K/9 2.5, BB/9 1.2, HR/9 .45다. 모든 조건과 리그 RA9 차이 .6 이내를 동시에 요구하고 정규화 거리 최소 후보를 선택했다. 이 허용 범위는 공식 기준이 아닌 감사용 게임 가정이며 완전히 같은 시즌이라는 의미가 아니다.

직접 확인하지 못한 것은 실제 시즌별 구장 계수, 전체 부 포지션·수비 추적 자료, KBO Fancy Stats의 완전한 가치 배분 공식, STATIZ 원표·산식이다. 공개 모델과 수치가 같은 정밀 WAR라고 표시하지 않는다. 기존 리그·구장 문맥 자체가 없는 과거 저장은 임의의 2024 평균으로 소급 계산하지 않는다.
