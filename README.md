# 차라리 내가 키운다

브라우저에서 고교 선수부터 은퇴까지 진행하는 야구 커리어 시뮬레이션 게임입니다. 게임 ‘이번 생은 야구다’에서 영감을 받아 제작 중입니다. 팀·학교·선수와 경기 결과는 가상이며, 같은 시드와 선택은 같은 결과를 만듭니다.

**비영리·비공식 팬 프로젝트**로, KBO나 구단·학교의 제휴·승인을 받은 서비스가 아닙니다. 실제 규정을 참고하되 모든 시즌의 실제 운영을 재현하지는 않습니다.

## 시작하기

macOS에서는 [`open-game.command`](open-game.command)를 실행하면 로컬 서버가 시작되고 Chrome에서 게임이 열립니다. 다른 환경에서는 저장소 루트에서 다음 명령을 실행하세요. 별도 빌드나 패키지 설치는 필요하지 않습니다.

```bash
python3 -m http.server 5173 --bind 127.0.0.1
# 브라우저에서 http://127.0.0.1:5173/ 열기
```

`index.html` 파일을 직접 열면 ES 모듈과 저장 기능이 제한될 수 있습니다. `localhost`와 `127.0.0.1`은 브라우저에서 서로 다른 저장 공간을 사용합니다.

```bash
npm test
node tests/balance.js
node tests/kbo-team-balance.js
node scripts/season-integrity-audit.mjs
```

첫 줄은 회귀 테스트입니다. 나머지는 고정 시드 표본을 돌리는 밸런스·리그 감사 명령이며 실행 시간이 더 걸립니다. 추가 감사 명령과 측정 조건은 [검증 기록](docs/verification.md)과 각 감사 문서에 있습니다.

## 플레이 흐름

고교 이름과 희망 포지션을 정하고, **오버롤이 같은** 능력치 후보 세 명 중 하나를 고릅니다. 고교·대학 시즌을 거쳐 드래프트에 참가하며, 자격을 충족하면 육성선수 입단도 선택할 수 있습니다. 프로에서는 시즌과 스토브리그를 반복하며 훈련, 1·2군 경쟁, 부상·재활, 연봉 협상, FA, 이적, 병역과 은퇴를 경험합니다.

시즌 진행 화면은 계산된 결과를 24단계에 걸쳐 재생합니다. 부상이나 시즌 중 이적처럼 확인·선택이 필요한 사건이 생기면 해당 지점에서 멈추고, 처리 후 이어서 진행합니다. 능력치가 선수별 상한에 도달하면 그 항목은 훈련 중점에서 해제되고 다시 선택할 수 없습니다.

은퇴 후에는 통산·시즌별 기록, 수상, 주요 커리어 사건과 수입 내역을 볼 수 있습니다. 총수입은 시즌별 연봉, 계약금, **실제로 지급된** 성과 옵션 및 군 보류수당을 구분해 합산합니다.

## 주요 게임 규칙

- **리그와 로스터:** 1군 144경기, 2군 108경기를 진행합니다. 구단별 AI 선수 명단은 시즌을 넘어 유지하며 신인 유입, 성장, 은퇴, 트레이드를 반영합니다. 1군 등록 명단과 경기 출장 가능 명단은 따로 선정합니다. 시즌 막판 확대 엔트리 중 미래 연도 일정은 게임 가정입니다.
- **입단과 성장:** 일반 지명 신인은 대체로 2군에서 시작하지만 즉시전력 예외가 있습니다. 육성선수는 개막 2군에서 시작하며 5월 1일 이후 정식 등록을 거쳐 1군 콜업 대상이 됩니다. 출전량·나이·잠재력·훈련·부상이 성장과 하락에 영향을 줍니다. 2군 AI 출장량은 1군 미출장량을 바탕으로 추정합니다.
- **경기와 보직:** 선발 로테이션과 마무리 보직을 유지하며, 휴식·점수 차·역할에 맞춰 투수를 기용합니다. 승리투수의 선발 5이닝 조건, 세이브 상황과 홀드 기회를 구분합니다. 유효한 세이브 기록이 없으면 세이브왕을 수여하지 않습니다.
- **구단 운영:** 시즌 중 구단 간 트레이드는 게임 달력의 7월 31일 마감까지 허용합니다. 플레이어가 이적하면 알림을 확인한 뒤 같은 시즌 진행 지점으로 돌아옵니다. 어린 유망주의 방출 판단에는 최근 여러 시즌의 성적, 포지션 경쟁, 프로 연차와 수상 이력을 반영하고 이유를 남깁니다.
- **계약과 병역:** FA 계약의 보장액·옵션·계약 기간과 FA 재취득 진행은 별도로 계산합니다. 실제 달성한 옵션만 지급합니다. 아시안게임 우승에 따른 병역특례를 적용하며 WBC·프리미어12 우승에는 적용하지 않습니다. 상무 선발 인원, 28세 시즌 자동 입대, 군 복무 중 경기·훈련의 상세 처리는 게임 모델입니다.
- **수상과 기록:** 공식 비율 타이틀의 자격은 144경기 기준 446타석 또는 144이닝으로 판정합니다. 골든글러브 투수 부문은 한 명, 외야수 부문은 세 명을 선정합니다. 신인왕의 공식 자격과 게임 내 수상 평가 표본은 구분합니다. 커리어 하이·로우에는 타자 규정타석의 50% 이상, 선발 규정이닝의 50% 이상, 불펜 규정이닝의 25% 이상을 채운 시즌만 비교합니다.
- **포스트시즌:** 정규시즌 기록과 포스트시즌 기록을 분리합니다. 개인 포스트시즌 출전 대상은 시즌 중 1군 등록 이력과 명단 제출 시점의 건강한 1군 상태로 판단하고, 선정·미선정 이유를 시즌 결과에 표시합니다. 이 조건은 게임의 단순화된 선정 기준입니다.
- **백분위:** 같은 리그 타자·투수를 각각 규정타석·규정이닝 대비 25%·50%·75%·충족 집단으로 나눕니다. 선수의 집단과 그보다 많은 타석·이닝을 소화한 집단을 비교하며, 비교 선수가 두 명이어도 차트를 표시합니다.

## 저장과 이전 버전

현재 커리어는 브라우저의 `charari-naega-kiunda-v7` 키에, 은퇴 선수 목록은 `charari-naega-kiunda-careers` 키에 따로 저장됩니다. 주요 선택과 사건은 자동 저장됩니다. 브라우저 저장 데이터는 용량을 줄이기 위해 일부 반복 기록을 압축하지만, **JSON 내보내기 형식은 유지**하며 이전 비압축 저장도 읽습니다. 과거 저장에 없던 상세 기록은 추측해서 채우지 않습니다.

상단 **보관·저장**에서 JSON 내보내기·불러오기와 현재 선수, 은퇴 선수, 구버전 저장·백업의 개별 삭제를 할 수 있습니다. 삭제 전 필요한 기록을 내보내세요. 저장 공간 문제의 재현과 수정 범위는 [저장 오류 분석](docs/2026-10-07-postseason-save-fix.md) 및 [저장 공간·트레이드 점검](docs/2026-10-08-storage-trades.md)에 있습니다.

## 규정 근거와 검증 범위

[2026 규칙](docs/2026-rules.md)은 확인한 KBO 규정의 적용 연도와 게임 가정을 구분합니다. 특히 미래 대회의 대표팀 선발 정책, 확대 엔트리 일정, 상무 경쟁률, 구단별 급여·전력 판단은 확정된 실제 운영이 아닌 게임 모델입니다. 포스트시즌의 개인 출전 기준도 실제 KBO의 모든 명단 변경 상황을 재현하지 않습니다.

최근 문제별 원인과 고정 시드 결과는 다음 문서에서 확인할 수 있습니다.

| 저장 공간·트레이드 빈도 | [2026-10-08 점검](docs/2026-10-08-storage-trades.md) |

| 리그 엔트리·신인·구단 운영 | [리그 운영 감사](docs/2026-10-07-league-operations-audit.md) |
