# 다이아몬드 데이즈

브라우저에서 진행하는 KBO 커리어 시뮬레이션 게임입니다. 구단명 외의 선수와 경기 결과는 가상이며, 같은 시드와 선택은 같은 결과를 만듭니다.

## 실행과 검증

```bash
python3 -m http.server 5173 --bind 127.0.0.1
# http://127.0.0.1:5173/
node --test tests/*.test.js
node tests/balance.js
```

별도 빌드나 패키지 설치가 필요 없는 ES 모듈 앱입니다. 브라우저에서 `localhost`와 `127.0.0.1`의 저장 공간은 다릅니다.

## 화면 흐름

선수 생성 → 고3 시즌 진행 → 시즌 결과 → 드래프트·대학 진로 → 드래프트 결과 → 스토브리그 → 프로·대학 시즌 진행 → 시즌 결과 → 다음 스토브리그를 반복합니다. FA 선언·제안, 병역, 재활, 포지션 변경, 트레이드 요청과 은퇴는 해당 시점에 열립니다. 기록·리그·이력·규칙은 상단 탭으로 확인합니다.

스토브리그의 훈련·연봉 결정과 주요 사건 확인 단계는 자동 저장됩니다. 시즌 결과 계산 후 베이스가 순서대로 채워지는 약 2.4초 진행 모션이 표시됩니다. 건너뛰기와 빠른 진행을 제공하고 `prefers-reduced-motion` 환경에서는 곧바로 결과를 엽니다. 계산 직후 저장하므로 모션 중 새로고침해도 결과가 복구됩니다. 국가대표 선발, 이적, 방출, 웨이버 결과는 확인 화면에서 멈춥니다.

## 시뮬레이션 규칙

- 1군은 144경기, 2군은 108경기입니다. 2군 성적은 표본과 비율을 함께 확인해야 합니다. 육성 입단자는 첫 시즌 기본적으로 2군부터 시작하고, 이후 성적·표본·팀 상황을 반영해 승격됩니다.
- 선발은 투구 상대량·실점·체력·감독 판단에 따라 교체됩니다. 구원 투수는 휴식·점수 차·보직에 따라 기용됩니다. 승리투수의 선발 5이닝 조건, 세이브 상황과 홀드 기회를 구분합니다.
- 현역 복무에는 구단 훈련과 공식 경기가 없습니다. 상무 복무는 가상 퓨처스리그 경기를 진행합니다. 매년 지원 기회는 제공하지만 합격은 경쟁 결과에 따릅니다. 화면의 모집 인원과 지원 최소 조건은 게임 규칙이며 실제 공고 인원·자격을 뜻하지 않습니다.
- 등록일은 게임의 188일 가상 시즌에서 1군 엔트리 상태를 일별로 기록합니다. 과거 v1 저장의 등록일은 경기 수로 추정한 값이며 결과 화면에서 별도로 표시합니다.
- 백분위는 같은 리그의 타자·선발·구원을 나눕니다. 누적 기록과 비율 기록마다 자격 표본과 비교 인원 수를 표시하며 10명 미만이면 숨깁니다. 누적 기록은 출장량에 영향을 받습니다.
- FA 제안은 최근 3개 시즌 성적, 출전량, 나이, 수비 포지션, 구단 수요를 반영합니다. 연봉·계약금·성과 옵션·보장액을 따로 표시하고 실제 달성한 옵션만 지급합니다. FA 등급은 본인의 최근 3년 급여와 가상 선수 급여 순위로 산정한 게임 추정치입니다.
- 공식 비율 타이틀은 144경기 기준 446타석·144이닝이 필요합니다. 구원투수의 백분위 표본은 별도 기준을 씁니다. 2차 드래프트, 웨이버, 보류선수 제외와 자유계약은 별도 신분으로 처리합니다.

## 저장 호환성

`diamond-days-v2` 키에 버전 3 데이터를 저장합니다. v1·v2 저장을 읽을 때 과거 경기 기록을 보존하며, 없던 2군 기록과 지급 연봉은 만들어 채우지 않습니다. JSON 내보내기·불러오기를 지원합니다.
